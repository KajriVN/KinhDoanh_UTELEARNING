UTELearn — Tài liệu bàn giao (hand-off)

Nền tảng kinh doanh khóa học trực tuyến & quản lý học tập số · Đồ án môn Lập trình Web · cập nhật 03/10/2026 (đã làm hết mục 8)

File này dành cho người/agent làm tiếp. Đọc hết mục 1–4 trước khi code, sau đó chọn việc ở mục 8. Cả 34/34 chức năng trong bảng mục 5 đã có code: luồng chính (tài khoản, khóa học, giỏ hàng, thanh toán giả lập + VNPay, học bài, tiến độ, chat realtime, giảng viên, admin) và toàn bộ phần mở rộng ở mục 8 (bài tập, coupon, đánh giá, thông báo realtime, quên mật khẩu, biểu đồ, chatbot AI, chứng chỉ PDF, hỏi đáp, wishlist, quiz, REST API). Việc còn lại nằm ở mục 9 (nợ kỹ thuật), mục 10 (tài liệu nộp) và mục 12.

  1. Mở MySQL Workbench → chạy database/utelearn.sql (tạo DB utelearn + 17 bảng + dữ liệu mẫu).
  2. Sửa user/pass trong src/main/resources/application.properties hoặc đặt biến môi trường DB_USERNAME, DB_PASSWORD (mặc định root / 123456).
  3. mvn spring-boot:run → mở http://localhost:8080.
Máy dev hiện tại cổng 8080 đang bị chương trình khác chiếm. Chạy với --server.port=8088. File .claude/launch.json đã cấu hình cổng 8088.

4. Quy ước code (giữ đúng để code đồng bộ)

Yêu cầu của nhóm: code sạch nhưng đơn giản, kiểu sinh viên — không over-engineer. Cụ thể:

  • Service là class thường (không tách interface + impl). Inject bằng constructor, không dùng @Autowired field.
  • Entity dùng Lombok @Getter @Setter @NoArgsConstructor (không dùng @Data). Tên bảng/cột snake_case khai báo rõ bằng @Table/@Column.
  • Comment tiếng Việt, ngắn, chỉ ở chỗ cần giải thích "tại sao".
  • Lỗi nghiệp vụ: service ném BusinessException("thông báo tiếng Việt") → controller try/catch → redirect.addFlashAttribute("error", e.getMessage()). Thành công thì "success". Fragment flash tự hiện.
  • Không tìm thấy: ném NotFoundException → trang 404. Sai quyền: ném org.springframework.security.access.AccessDeniedException → trang 403. Không bắt 2 loại này trong controller.
  • Lấy user hiện tại trong controller: tham số Principal principal → userService.findByEmail(principal.getName()). Trong template đã có sẵn ${currentUser} và ${cartCount} (GlobalModelAdvice).
  • Kiểm tra quyền sở hữu khóa học: dùng courseService.getOwnedCourse(id, user) / canManage(course, user) (admin luôn được).
  • Form: th:action + method="post" (Thymeleaf tự chèn _csrf). Form có file thêm enctype="multipart/form-data". Validate bằng DTO + @Valid + BindingResult.
  • Hiển thị tiền: ${@fmt.money(x)} / ${@fmt.price(x)} (0 → "Miễn phí"). Ngày: ${@fmt.dateTime(t)}. Phân trang: ~{fragments/layout :: pagination(${page})}.
  • Trang mới copy khung từ trang có sẵn: head(title) → navbar → main (+ flash) → footer. Trang GV/admin có cột trái instructorMenu('key') / adminMenu('key'). Các mục "sắp có" trong menu là chỗ gắn chức năng mới.
  • Upload file: luôn qua FileUploadService (uploadImage, uploadVideo, uploadDocument cho file pdf/doc/zip).
  • Đánh dấu chỗ chưa làm bằng comment // TODO (hand-off): ... — tìm nhanh: grep -rn "TODO (hand-off)" src (hiện không còn chỗ nào).

11. Đã test những gì

  • Smoke test bằng curl (70 bước): khách, đăng ký/đăng nhập, học viên mua khóa → thanh toán → học → tiến độ, phân quyền 403, admin (user, danh mục, duyệt/từ chối), giảng viên (tạo khóa có upload ảnh multipart, thêm chương/bài, gửi duyệt), link Youtube → embed. Kết quả: tất cả pass (2 lần fail ban đầu là do script test sai kỳ vọng / lỗi mã hóa tiếng Việt của Git Bash, không phải lỗi app).
  • Chat WebSocket: client STOMP Python — HV gửi, GV nhận và ngược lại; người không thuộc cuộc trò chuyện bị chặn.
  • database/utelearn.sql nạp vào H2 (MySQL mode) + chạy app với ddl-auto=validate: schema khớp entity, đăng nhập bằng tài khoản trong SQL được.
  • Test end-to-end bằng trình duyệt thật (Edge headless, shots.js): khách → học viên (thêm giỏ, thanh toán, học, chat) → giảng viên → admin, 31 trang. Chính bước này phát hiện lỗi CSRF #1 ở mục 13 (curl không phát hiện được vì không tải CSS/JS). Sau khi sửa: toàn bộ luồng chạy đúng, smoke test + test WebSocket chạy lại đều pass.
  • 03/10 — bài tập (35 bước, script Python requests, H2): GV tạo bài (validate tên trống, chặn file .exe, gắn bài học, có hạn nộp) → HV nộp file (bắt buộc file lần đầu, nộp lại giữ file cũ, chặn quá hạn) → GV chấm (chặn điểm > tối đa) → HV thấy điểm + nhận xét, không nộp lại được. 13. Nhật ký lỗi đã gặp

Tất cả lỗi gặp trong quá trình làm, kể cả lỗi môi trường và lỗi của script test, để người sau không mất thời gian dò lại.

#Lỗi / hiện tượngNguyên nhânXử lýTrạng thái
1 Sau khi đăng nhập, mọi form POST trên trình duyệt đều lỗi (thêm giỏ, thanh toán, lưu hồ sơ...) → hiện trang "405". Test bằng curl thì vẫn qua. Dùng JWT + SessionCreationPolicy.STATELESS làm SessionManagementFilter coi mỗi request là 1 lần đăng nhập mới → CsrfAuthenticationStrategy xóa và tạo lại cookie XSRF-TOKEN ở mọi request, kể cả request tải CSS/JS/favicon. Khi bấm submit, token trong form đã cũ → CSRF bị từ chối. Curl không tải CSS/JS nên không thấy. SecurityConfig: csrf.sessionAuthenticationStrategy(new NullAuthenticatedSessionStrategy()). Kiểm chứng: cookie giữ nguyên qua các trang (docs/tools/debug_csrf.js), chạy lại toàn bộ luồng trên trình duyệt OK. ĐÃ SỬA
2 Lỗi CSRF/thiếu quyền ở request POST hiện trang 405 thay vì 403. Spring Security forward request (giữ method POST) tới /403, nhưng HomeController chỉ có @GetMapping("/403"). Đổi thành @RequestMapping("/403"). ĐÃ SỬA
3 Khởi động profile h2 chậm (~10 giây chỉ để mở DB). URL H2 có AUTO_SERVER=TRUE. Bỏ tham số này trong application-h2.properties. ĐÃ SỬA
4 Dòng log "Đã tạo dữ liệu mẫu" bị lỗi font trên console Windows. System.out in tiếng Việt có dấu, console dùng code page khác UTF-8. Dùng SLF4J logger + chữ không dấu trong DataSeeder. ĐÃ SỬA
5 Nút "Tìm kiếm" ở banner trang chủ bị xuống 2 dòng khi màn hình hẹp. Thiếu white-space: nowrap. Thêm class text-nowrap. ĐÃ SỬA
6 Không chạy được ở cổng 8080. Máy dev có chương trình khác đang chiếm 8080 (không liên quan dự án). Chạy với --server.port=8088; .claude/launch.json dùng 8088. MÔI TRƯỜNG
7 mvn không có trong PATH; lần tải dependency đầu báo Premature end of Content-Length (byte-buddy). Máy chưa cài Maven; lỗi mạng tạm thời. Dùng Maven 3.8.5 có sẵn trong ~/.m2/wrapper/dists; chạy lại là tải được. Nên thêm Maven Wrapper (mvn wrapper:wrapper) vào repo. MÔI TRƯỜNG
8 Dữ liệu tiếng Việt gửi bằng curl trong Git Bash bị lưu thành dấu "?" (vd "Video chua r?"). Git Bash chuyển tham số dòng lệnh sang code page Windows trước khi đưa cho curl. Không phải lỗi app: gửi UTF-8 đã encode sẵn hoặc nhập trên trình duyệt đều lưu đúng. Khi test bằng curl dùng dữ liệu đã URL-encode (--data "name=Ki%E1%BB%83m..."). LỖI SCRIPT TEST
9 Smoke test báo FAIL "GET /learn/3 (chưa mua) mong đợi 302 nhưng ra 200". Kỳ vọng của test sai: bài đầu tiên của khóa React là bài học thử nên được xem → 200 là đúng. Sửa lại kỳ vọng trong smoke.sh nếu dùng tiếp. LỖI SCRIPT TEST
10 Chạy app với spring.main.web-application-type=none (để sinh DDL) không tự thoát. Thread của WebSocket message broker không phải daemon. Chạy kèm timeout 75; file DDL đã sinh xong trước đó. MÔI TRƯỜNG
11 Script tạo file Java bằng bash heredoc báo unexpected EOF while looking for matching '. Quoting của bash tool với nội dung có dấu nháy đơn. Chuyển sang ghi file trực tiếp. MÔI TRƯỜNG
12 Sơ đồ kiến trúc tổng quan render lần đầu bị rối, đường nối cắt nhau. Bố cục flowchart LR với nhiều cạnh 2 chiều. Viết lại theo flowchart TB 3 tầng (trình duyệt / server / lưu trữ). ĐÃ SỬA
13 render_code.js cắt đoạn code sai khi comment phía trên hàm có {email}. Bộ đếm ngoặc bắt đầu đếm từ dòng comment. Đếm ngoặc từ dòng khai báo hàm. ĐÃ SỬA
14 Chat: người không thuộc cuộc trò chuyện gửi tin thì bị chặn nhưng không nhận được thông báo lỗi. ChatController.sendMessage chỉ bắt BusinessException, còn AccessDeniedException chỉ được log. Bắt thêm AccessDeniedException và gửi /user/queue/errors. CHƯA SỬA
15 Chưa kiểm tra với MySQL thật và Cloudinary thật. Máy dev không có MySQL server, Docker không chạy; chưa có tài khoản Cloudinary. Đã kiểm tra thay thế: SQL nạp vào H2 chế độ MySQL + ddl-auto=validate pass; upload test ở chế độ lưu local. CẦN KIỂM TRA
16 Git cảnh báo LF will be replaced by CRLF khi commit. .gitattributes có text=auto trên Windows. Vô hại, bỏ qua. VÔ HẠI
